# SECURED-Knowledge-Base

This repository contains the implementation of the Knowledge Base system developed by ICCS for Task 4.3 of the SECURED EU H2020 project.

## Installation

Install the required dependencies:

```bash
pip install -r requirements.txt
```

## Usage

Run the script to download TCN server or client Docker files:

```bash
python script_fl_download.py
```

Edit `script_fl_download.py` to uncomment the appropriate lines depending on whether you are the server or client.
